# Database-Management-System

Problem Statement:
1. Traditional banking systems are challenged with the following:
2. Data breaches and unauthorized access.
3. Lack of data traceability and poor auditing
4. Poor password storage and checking mechanisms
5. Lack of data encryption measures.These problems require a safe database system that can safeguard sensitive information and provide an easily traceable audit of all financial transactions.

3. Objectives:
The key goals of this project are:
● To design and develop a secure and normalized database for banking application using Microsoft SQL Server
● Encrypting sensitive data attributes such as emails, phone numbers, account numbers, etc.
● To use password hashing and account verification using HASHBYTES().
● To keep an audit log of all database actions - using triggers
● To implement role based access control (RBAC) for various banking staff.

4. System Overview:
The suggested system deals with the end-to-end interactions of banking operations such as:

● Customer registration and KYC identification.
● Real estate account creation and maintenance.
● Transaction recording and resolution of conflict.
● Role-based login and password protected authentication.
● Secure encryption of customer confidential data.
● Automatic auditing of all changes in the database.
